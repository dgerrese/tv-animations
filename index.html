Or let the Chromecast run it on its own, without a tab: see the bottom of this page.

    Cast without keeping a tab open

    With catt, the Chromecast opens the animation in its own browser. Once it runs, you can close everything on your computer; it keeps playing until you stop it or cast something else. Your computer only has to be on the same Wi-Fi as the Chromecast to start it.

    1. Install catt (needs Python): 
      pipx install catt
      or pip install catt.
    2. Find your Chromecast's name: 
      catt scan
